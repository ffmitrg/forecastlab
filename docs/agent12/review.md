# 整分支自检记录

审核类型：当前会话自检，不是独立审查员审阅。

自检前已有 96 个后端测试与 11 个浏览器测试通过。随后针对遗漏边界补充六项失败测试，再修改实现：

| 新发现 | 修复与证明 |
|---|---|
| 导入路径缺少内容去重 | 规范化 URL/正文哈希去重，保留所有别名时间与来源声明 |
| 修订成功后同操作重试被当成旧版本 | 先核对操作哈希和已完成结果，再检查新请求的 expected_revision |
| 教学父运行可被真实 reuse 读取 | 新旧真实入口均拒绝复用 demo 父运行；原历史复用测试换为非 demo 的固定模型导入，断言保留 |
| 失败准备请求不易从草稿查看 | 草稿读取返回 preparation_records，失败和未知 token 可见 |
| 恢复时间可能重置/并行重复计算 | 请求区间并集计算，并在阶段边界保存活动时间 |
| 一个查询同时针对否认/保留前提 | 整条带被否认目标的查询丢弃，不留下旧措辞误导后续检索 |

上述六项先运行失败再实现修复，修复后 102 个后端与 11 个浏览器测试通过。包装脚本另增加三个失败测试，再验证仅打包已提交允许文件、成员哈希与干净基线补丁应用。

基线最初有一个依赖现实日期的测试失败（28 通过、1 失败）。只将该测试的时钟固定到自身教学夹具截点，未修改生产历史证据校验；基线复测 29 通过。

已人工查看本机真实浏览器生成的桌面与 390px 移动端截图，确认来源筛选、警告、原文高亮、抽屉布局可读。更广泛的可用性走查、真实模型语义及第三方独立代码审阅仍未执行。
