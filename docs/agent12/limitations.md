# 局限与未执行项

## 不是已经完成的研究结论

本次交付完成软件实现、固定夹具自动化验证与本机浏览器联调。没有使用真实模型或 Tavily 的有效账户配置进行端到端研究问题测试；没有测量真实假设识别准确率、证据支持率、中性/引导性问题稳健性、预测校准或费用收益。模型提示词中要求“保留范围”“不要伪造反证”，不能因此宣称已经证明模型会正确做到。

固定教学输出和虚构资料只用于无密钥演示。题对评估中的两条输入属于同一个虚构事件，不是独立样本。`semantic_review=not_performed` 不可改写成通过。

## 来源与语义

正文哈希和引用定位只证明保存内容与引用匹配，不证明资料真实、一手来源权威或推理成立。一手/二手来源分类保守记录；导入者声明不被包装成系统已核实。来源根自动识别仅覆盖明确转载线索；高文本重叠只标疑似，仍需要人工判断。

只取得搜索摘要时不称正文。最多保存二十万码点正文，服务商未返回的内容从未保存。段落相关性采用轻量词项重叠而非经过评测的语义检索模型，可能漏掉间接相关段落。模型上下文仍受预算限制，省略发现会写明限制；不表示被省略发现不存在。

时间未知保持未知。没有精确时区的服务商日期按 UTC 记录并注明依据，不授予“截点前已验证”状态。今天取得、声称以前发布的网页，不能自动证明以前版本内容未变；严格盲回测仍需要可验证的冻结快照与独立核查。

## 操作与部署

定位是单用户、单 Uvicorn worker、本机演示，不新增认证、租户隔离、分布式队列和权限系统。启动脚本只监听 127.0.0.1。不要未经加固就把新服务直接暴露到互联网。

每个运行最多一个搜索批次，失败或中断不在恢复时默默重发搜索。重新联网需要新运行；模型分析阶段可复用已保存来源继续。准备调用与运行调用分开记录，再一起检查总预算；复用同一准备记录评估费用时按 request_id 去重。进程突然消失时，部分请求真实 token 和精确活动时长无法重建，保留未知或保守时间，不编造精确账单。

没有新增直接抓取任意网址的浏览器工具，因此不能处理所有动态网页或登录资料。模型负责提出候选而非自带互联网能力。

## 测试与审核范围

测试系统使用固定模型输出、模拟搜索返回或严格固定教学数据；最终 Python 自动化测试全局阻断 httpx 的真实 HTTP 传输。浏览器测试十项拦截 API 响应，一项访问真实本机后端与 SQLite/LangGraph，但仍使用固定教学模型和资料。

本次进行了同一会话的整分支自检和新增边界回归，没有独立审查员或另一模型的代码审阅。现存第三方依赖产生两条弃用/默认值变更警告，不是零警告构建。只在用户 Mac 的 Python 3.12 与当前 Node 环境验证；补丁还会在同机干净基线中检查，不等于多平台测试。

一次新增边界回归的初始失败用例曾缺少模型桩，可能尝试使用无效字面量 `test-only` 发出请求。未读取或使用真实服务密钥。该测试已补齐桩，并增加最终测试全局禁止真实 httpx 出网的保护。

## 后续真实验证方式

由小组提供合规公开证据包和后端环境配置后，显式运行 `eval/agent12.py --mode live`，保留全部失败与未执行问题；让人工核查者检查问题范围、用户前提、原文支持关系及遗漏方向。第一次调用后先检查服务方实际账单，不以固定演示调用数声称费用。没有人工完成这些步骤前，不填写质量百分比。
